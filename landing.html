🌐 Public Sharing Setup

To share PCBot externally (office network, Google Sites, etc.), use the deployment script:

Quick Deployment

  1. Run the deployment script:
    .\run_widget_standalone.bat
  2. Wait for Flask to start and Cloudflare tunnel to be created (shows URL in console)
  3. Copy the tunnel URL (e.g., https://your-name.trycloudflare.com)
  4. Share the URL - it will show the widget interface by default
  5. For mobile version, add /mobile.html to the URL

Google Sites Embedding

  1. Get your Cloudflare tunnel URL from the bat file
  2. In Google Sites, insert an "Embed" block
  3. Paste the full URL (with /widget-standalone.html or /mobile.html)
  4. Adjust iframe size as needed (recommended: width 100%, height 700px)
